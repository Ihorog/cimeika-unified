# Ci Symbol Manifest

## Core Rule

Ci = semantic center  
ci = technical namespace  
CI = continuous integration / pipeline  

Do not mix these layers.

---

## Canonical Symbols

Ci 1 0 = + - / × • ○ | — ∧ ∨ ~ Y ↺ 🜂 🜄 🜁 🜃 ⟁

---

## Meanings

Ci = center / contact / semantic fixation  
1 = fact / exists  
0 = absence / not active  
= = balance  
+ = closure / confirmed / aligned  
- = tension / open contour / needs attention  
/ = transition / route  
× = node / conflict / crossing  
• = seed / origin  
○ = core / eye / center  
| = axis / structure  
— = field / plane  
∧ = force / manifestation  
∨ = base / root / grounding  
~ = flow / wave / movement  
Y = branching / growth / choice  
↺ = cycle / return / evolution  
🜂 = fire / initiation  
🜄 = water / adaptation  
🜁 = air / idea  
🜃 = earth / fixation  
⟁ = ether / harmonizing field  

---

## Usage Zones

Allowed:
- docs
- manifests
- Ci Moment
- artifact metadata
- semantic UI overlays
- perception layer
- Kazkar / Legend Ci content

Forbidden by default:
- filenames
- environment variables
- database columns
- low-level API params
- CI/CD workflow ids
- package names

---

## Naming Contract

Use:

- Ci for semantic center
- ci for machine identifiers
- CI for pipeline / build / test / deploy

Examples:

Correct:
- Ci Moment
- Ci Core
- ci_state
- ci_gitapi
- CI/CD

Incorrect:
- CI Moment
- Ci workflow
- ci as user-facing brand title
