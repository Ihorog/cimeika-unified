# Operator Runtime v0.2

Purpose:
This layer turns symbolic operators into runtime state.

Added concepts:
- attention
- tension
- resonance
- stability
- vector
- fact

Runtime formula:
symbol sequence → operators → runtime state → decision signal

Example input:
○+∧→

Meaning:
center
+ confirm
+ active force
+ forward vector

Runtime output:
attention rises
resonance rises
stability rises
forward vector activated

Rule:
Symbols are not decorative.

Each symbol compiles into:
- operator id
- state effect
- graph relation
- runtime signal
