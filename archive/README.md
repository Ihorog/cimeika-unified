## When to Use Archive

**Reference archived files when:**
- Investigating historical decisions
- Understanding migration from Flask to FastAPI
- Researching the evolution of CI Legends implementation
- Needing context on superseded approaches

**Do not:**
- Use archived code in production
- Reference archived documentation as current
- Duplicate archived content back into active docs
