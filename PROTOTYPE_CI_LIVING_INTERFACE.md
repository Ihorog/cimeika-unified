# Ci Living Interface Prototype

Branch: `ci-living-interface-20260912`

Prototype principles:
- Ci is the primary navigation object.
- No permanent menu or dashboard.
- Single tap reveals contextual projections.
- Double tap opens the voice channel.
- Ci can be moved freely in the spatial field.
- Interfaces appear only when the current intent requires them.
- Four outward states: PASSIVE, CONTEXT, VOICE/CONFIRM, RESULT.
- Existing `status.json` is used only as live evidence when available.

This branch is isolated from production until reviewed.
